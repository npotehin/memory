# Память

Репозиторий консьержа: отчёты, стили, заметки по проектам.

## Что внутри

```
styles/       оформление HTML-отчётов
projects/     по папке на проект, PROJECT.md внутри
dashboard/    index.md — короткий список проектов
```

## Правила

- Каждое изменение — отдельный коммит с понятным сообщением.
- Ничего важного не решается молча.
- Секретов здесь нет: только ссылки на настройки.
