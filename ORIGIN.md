# Происхождение файлов

Три вида пометок. В шапке каждого файла стоят такие же.

## Оригинал разработчика, репозиторий не менял

Файл целиком чужой. Мы получили его из каталога скиллов и записали без правок.

Пометка в шапке:
`ПРОИСХОЖДЕНИЕ: ОРИГИНАЛ, НЕ ИЗМЕНЁН`

## Оригинал разработчика, есть наши правки

Автор — по-прежнему разработчик. Мы внесли правку, она перечислена в шапке.
Рядом всегда лежит нетронутый оригинал для сверки.

Пометка в шапке:
`ПРОИСХОЖДЕНИЕ: АВТОР — РАЗРАБОТЧИК СЕРВИСА. ЕСТЬ НАШИ ПРАВКИ.`
и строки `Оригинал:` / `Правки:` / `Зачем:`

## Что где лежит

| Путь | Что | Происхождение |
|---|---|---|
| `skills-src/*/SKILL.md` | тексты скиллов | оригинал разработчика |
| `skills-src/mobile-reports/origin/` | нетронутые копии для сверки | оригинал разработчика |
| `skills-src/mobile-reports/scripts/site.cjs` | рабочий скрипт | оригинал + наши правки |
| `skills-src/mobile-reports/scripts/build_mindmap.cjs` | рабочий скрипт | оригинал, не менялся |
| `skills-src/mobile-reports/scripts/archive/` | аналог на открытых библиотеках | наше, не подключён |
| `htmlkit.py`, `build_index.py`, `build_styles_index.py` | сборщики страниц | наше |
| `*.html` в корне | отчёты и ленты | наше |
| `dashboard/`, `projects/` | память проектов | наше |

## Правило

Взяли чужой файл и тронули хоть строку — пишем в шапке, что автор разработчик,
что именно мы изменили и оставляем оригинал рядом. Чтобы через полгода было
видно, где чьё, не открывая историю git.
