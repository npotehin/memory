Причина найдена

GitHub Actions в аккаунте не запускаются вовсе. Дело не в настройках и не в коде — задание не стартует, потому что у аккаунта не решён вопрос с минутами.

The job was not started because recent account payments
have failed or your spending limit needs to be increased.

Для приватного репозитория минуты Actions платные. Именно поэтому все четыре запуска упали за секунду, а логов нет — их не успело появиться.

Что мы проверили, прежде чем найти этопоказать

Токены GitHub и Cloudflare — активны и рабочие. Секреты в репозитории на месте. Workflow правильный: сборка локально проходит чисто.

Падало всегда на первом шаге — до кода дело не доходило. Это и стало подсказкой.

Не через Actions

Cloudflare подключается к репозиторию напрямую. Тогда GitHub Actions не участвуют вообще, минуты не тратятся, настройка одна.

Проверено: к проекту Git ещё не подключён, источника нет.

ПОДГОТОВКА В GITHUB

1. dash.cloudflare.com, Workers and Pages, проект memory.
2. Settings, Build configuration, Connect Git.
3. Авторизовать GitHub. Дать доступ ТОЛЬКО к npotehin/memory,
   не ко всем репозиториям.
4. Выбрать репозиторий npotehin/memory, production branch: main.
5. Framework preset: None.
6. Build command: оставить ПУСТЫМ.
7. Build output directory: точка ( . )
8. Root directory: пусто.
9. Сохранить и запустить деплой.

ПОЧЕМУ БЕЗ СБОРКИ
index.html и styles/index.html уже лежат в репозитории собранными.

Про полный доступ

Текущего токена хватает. Он с правами Account → Cloudflare Pages → Edit, срок — бессрочный.

Для подключения Git этого достаточно: настройка проекта, деплой, передеплой, удаление. Больше прав не понадобится.

Если всё же понадобится расширитьпоказать

Новый токен создаётся в My Profile → API Tokens → Create Token. Права: Account → Cloudflare Pages → Edit, плюс при необходимости Account Settings → Read для просмотра биллинга.

Значение показывается один раз. После создания — обязательно прислать сюда, иначе доступ потеряется.
