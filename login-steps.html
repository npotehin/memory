Вход в аккаунты консьержа

Никита Потехин: GitHub, Cloudflare, Gmail. Что делать по шагам.

Что происходит

Три сервисных аккаунта на имя Никиты Потехина готовы. Дальше от вас нужен только вход — пароли в чат не идут, всё вводится на моём экране.

СервисСтатусЗачем
GitHubготовПамять, отчёты, коммиты
CloudflareготовПубликация ленты
GmailготовКоды подтверждения

Времени: 10–15 минут на вход, потом 20 минут моей работы без вас.

Открываю экран

Присылаю вам ссылку на живой браузер моей машины. Открываете с планшета — экран большой, удобнее вводить.

  1. Нажимаете ссылку, которую я пришлю отдельным сообщением.
  2. Видите рабочий стол и браузер. Управление у вас.
  3. Я в это время не подглядываю — пароль мне не виден.
Что будет, если ссылка попадёт не тудапоказать

Ссылка на экран — это и есть доступ. Никому не пересылайте её и не публикуйте.

Когда закончите, я закрываю экран, и по этой ссылке уже ничего не открыть.

Вход в GitHub

Открываете github.com, входите как Никита Потехин.

  1. Логин — тот, что вы задали при регистрации.
  2. Пароль — обычный ввод, на экране.
  3. Придёт код на ботовый Gmail — откроете почту в соседней вкладке там же, на экране, прочитаете и введёте.
  4. Если GitHub попросит настроить вход по ключу — нажмите «позже», мне достаточно пароля.
Почему код вводится на экране, а не в чатепоказать

Код подтверждения — это одноразовый ключ. Если он пройдёт через переписку, он останется в истории и в логах. На экране он живёт секунды и никуда не попадает, кроме самой формы.

Вход в Cloudflare

На том же экране открываете dash.cloudflare.com, входите тем же аккаунтом Потехина.

  1. Не вашим личным — именно сервисным.
  2. Если предложит вход через GitHub — можно так, аккаунты теперь связаны по имени.
  3. После входа вам нужен только дашборд, ничего настраивать не надо.
Если Cloudflare потребует токен вместо входапоказать

Можно и так: My Profile → API Tokens → Custom token, право одно — Account → Cloudflare Pages → Edit. Токен скопируете в репозиторий, в Secrets → Actions, как CLOUDFLARE_API_TOKEN.

Но проще просто войти: сессия сохранится в браузере, токен не понадобится.

Говорите «вошёл»

После этого я забираю управление и работаю без вас.

Что происходит дальше — по порядку:

  • создаю приватный репозиторий memory;
  • кладу структуру: стили, проекты, дашборд;
  • переношу четыре сегодняшних отчёта в новый вид;
  • собираю ленту index.html с историей файлов;
  • пишу workflow: лента пересобирается при каждом пуше;
  • подключаю Cloudflare Pages;
  • приглашаю вашу основную почту с правом чтения;
  • присылаю ссылку — открываете на планшете.

Три вещи, которые могут застрять

Не паникуйте — у каждой есть простое решение.

  1. Не приходит код. Проверьте папку «Спам» в ботовом ящике. GitHub иногда отправляет письмо с задержкой до минуты.
  2. GitHub просит настроить 2FA. Предложит приложение-аутентификатор — можно пропустить на этом этапе, вход по паролю сработает.
  3. Cloudflare не пускает по имени. Значит вход через почту или через GitHub-кнопку; если совсем никак — скажите, разберём на месте.
Самое важное правилопоказать

Если что-то пошло не так — не вводите пароль повторно и не создавайте новый аккаунт. Напишите мне, я посмотрю, что на экране, и подскажу.
