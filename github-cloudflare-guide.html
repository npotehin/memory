Шаг 1. Вход в GitHub

Вы заходите сами — на моём удалённом браузере, через живую ссылку на экран. Я в это время не подглядываю пароль.

  1. Я открываю экран и присылаю вам ссылку.
  2. Вы на телефоне или компьютере открываете её и видите браузер.
  3. Входите в GitHub как обычно: логин, пароль.
  4. Если GitHub просит код — он приходит вам на почту. Вводите его на экране, не в чат.
  5. Готово — говорите «вошёл», я забираю управление.
Почему через экран, а не «дай пароль»показать

Пароль, отданный в переписке, остаётся в истории чата навсегда. Через экран он вводится прямо в браузер и в переписку не попадает.

Сессия живёт в браузере на моей машине — значит, второй раз входить не придётся, пока вы сами не решите выйти.

Шаг 2. Приватный репозиторий

Репозиторий создаю я сам — сразу после входа. Видим только вы и я.

Структура, чтобы вы могли зайти и посмотреть:

memory/
├── styles/        стили отчётов, 01…0N + галерея index.html
├── projects/      по папке на проект, PROJECT.md внутри
├── dashboard/     index.md — всегда на виду
└── README.md
Что важно про приватностьпоказать

Приватный репозиторий виден только владельцу и тем, кому вы дали доступ. Токен, который вы выпустите, будет действовать на один этот репозиторий — не на весь аккаунт.

Шаг 3. Cloudflare Pages

Нужны два значения: токен API и Account ID. Оба — из панели Cloudflare.

  1. Войдите в Cloudflare (можно тем же способом — на экране).
  2. My Profile → API Tokens → Create Token → Custom token.
  3. Права: Account → Cloudflare Pages → Edit. Больше ничего.
  4. Скопируйте токен — он показывается один раз.
  5. Account ID — на странице Overview аккаунта, справа в блоке API.
Куда положить эти два значенияпоказать

В репозитории: Settings → Secrets and variables → Actions → New repository secret. Имена ровно такие:

CLOUDFLARE_API_TOKEN
CLOUDFLARE_ACCOUNT_ID

Это можно сделать и без вас — если вы дали мне доступ. Но лучше вы: секреты добавляются в интерфейсе за минуту и в переписку не попадают.

Про почту с подтверждениями

Пароль от Gmail я не возьму. Не из вредности — из правила: логины и пароли в чат я не принимаю и не храню.

Что работает вместо этого:

  • коды подтверждения приходят вам — вы читаете их сами и вводите на экране;
  • если хотите, чтобы я разбирал письма — это отдельный ящик, подключённый штатно, а не пароль от личного;
  • для GitHub и Cloudflare почта нужна только на этапе входа, дальше — токены.
Почему так, а не «просто дай доступ»показать

Ботовый Gmail — это ключ ко всему, что к нему привязано: восстановление паролей, подтверждения входов, сброс доступа. Даже если доверяете — такой ключ не должен проходить через переписку.

Практическая альтернатива: отдельный ящик для ботов, к которому доступ выдаётся через штатное подключение, а не паролем в чате.

Что делаю я

После входа и токенов работа идёт без вас.

  • создаю репозиторий и переношу стили (01, 02… + галерея);
  • пишу .github/workflows/pages-deployment.yaml для Cloudflare Pages;
  • проверяю сборку локально, потом пушу;
  • даю вам ссылку — открывается на iPhone из любого места.
Безопасность: как отозвать доступпоказать

Токен GitHub — срок 7 дней, потом новый. Отозвать: Settings → Developer settings → Personal access tokens → Delete.

Токен Cloudflare — My Profile → API Tokens → Roll/Delete. Вход в браузере — выйти из аккаунта на экране, и сессия умрёт.

Один репозиторий, одно право на запись — худшее, что может случиться: пропадёт доступ к этому репозиторию. Не ко всему аккаунту.
