Настройка деплоя своими руками

Готовый промт и порядок шагов, чтобы подключить репозиторий к Pages.

Да, вы правы

Cloudflare Pages подхватывает репозиторий сам — через интеграцию с GitHub, без Actions и без токенов.

Схема: репозиторий npotehin/memory уже есть, в Cloudflare подключаете его как источник, Pages собирает и публикует при каждом пуше.

↓

↓

Промт для настройки

Скопируйте целиком и отдайте своему ассистенту.

Настрой автодеплой статического сайта из GitHub в Cloudflare Pages.

ДАННЫЕ
Репозиторий: npotehin/memory (приватный)
Ветка: main
Аккаунт Cloudflare: Npotehinru@gmail.com
Account ID: 081043455ec916ea8b44e5053b3f046c
Проект Pages: memory (уже создан)
Адрес: memory-e7l.pages.dev

ЗАДАЧА
1. Cloudflare Dashboard, Workers and Pages, проект memory,
   Settings, Build configuration.
2. Подключить Git: GitHub, репозиторий npotehin/memory, ветка main.
3. Framework preset: None.
   Build command: python3 build_index.py && python3 build_styles_index.py
   Build output directory: /
4. Root directory оставить пустым.
5. Если Cloudflare не даёт указать python3, поставить
   PYTHON_VERSION=3.12 в переменных окружения.
6. Сохранить и запустить деплой.

РЕЗУЛЬТАТ
После сборки на memory-e7l.pages.dev открывается страница Обновления:
список HTML-файлов с датами. Любой пуш в main пересобирает сайт сам.

ВАЖНО
В репозитории есть .github/workflows/pages-deployment.yml. Он не нужен,
можно удалить, чтобы не было двойного деплоя.
Если Cloudflare требует выбрать только готовую папкупоказать

Тогда оставьте Build command пустым, а Build output directory — точкой . Файлы index.html уже лежат в репозитории собранными.

Минус: лента не будет обновляться сама при добавлении нового файла.

Что где нажимать

Сначала репозиторий, потом Cloudflare.

  1. Зайти на github.com под npotehin, убедиться, что memory виден.
  2. Зайти на dash.cloudflare.com под Npotehinru@gmail.com.
  3. Workers и Pages, выбрать проект memory.
  4. Settings, Build configuration, Connect Git.
  5. Авторизовать GitHub, выбрать npotehin/memory, ветка main.
  6. Framework: None. Build command и output — по промту.
  7. Save, затем Retry deployment.
Если репозитория нет в спискепоказать

Cloudflare показывает только те репозитории, к которым есть доступ. При подключении он спросит разрешение — дать именно к npotehin/memory.

Если не появляется: на GitHub Settings, Applications, Cloudflare Pages, Configure, дать доступ к репозиторию.
