# Интерактивная сводка

Создавай страницу, если пользователь её попросил или подборка требует удобной
навигации по многим темам/событиям. Короткий дайджест доставляй прямо в чат.
При отсутствии sandbox сохрани полезную текстовую сводку со ссылками.

## Страница

Штатному coder передай проверенные данные, период/timezone/checked_at, выбранные
темы, статусы и ограничения покрытия. Самостоятельный HTML должен содержать:

- Мобильную читаемую ленту событий и фильтры по темам/источникам/статусу.
- Поиск по тексту, раскрываемые детали и исходные ссылки у каждого события.
- Хронологию по подтверждённой дате события; неизвестную дату выделить отдельно.
- «Новое / обновление истории / контекст» только при наличии оснований.
- Сохранённые пользователем пункты и отметки прочитанного с localStorage.
- Экспорт выбранных пунктов и данных в JSON; печать без элементов управления.

Один набор данных должен определять карточки, фильтры, хронологию и экспорт.
Показывай число событий, а не число статей: несколько источников одного события
раскрываются внутри карточки. Не рисуй график «важности» из выдуманных чисел.
Покажи недоступные источники и время сбора рядом с границами периода.

Данные источников вставляй как текст, не как исполняемый HTML. Импорт JSON проверяет
форму данных и допустимые http/https-ссылки. Скрипты/iframe удалённых страниц не
встраивай. Внутренняя локальная отметка прочитанного не синхронизируется с источником
или krche. Не обещай live-обновление, совместный доступ или AI-ответы в офлайн HTML.
Для новых данных/разбора свободного вопроса пользователь возвращается к агенту.

## Проверка и доставка

Через доступный штатный browser-use открой файл, проверь мобильную ширину,
фильтры/поиск, раскрытие источников, сохранение после reload и экспорт.
Выборочно проверь существенные исходные ссылки; недоступные отмечай, а не удаляй
сам факт отказа. Получи скриншоты страницы и отправь их с HTML через send_file
по фактическим путям. Обозначь, если визуальная проверка недоступна.

Используй существующий хостинг только при его доступности и поручении пользователя.
Доставленный файл не является опубликованной или постоянно обновляемой лентой.
