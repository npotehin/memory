# Чтение ссылки и веб-исследование

Если человек дал конкретную ссылку, начни с её содержимого. Для воспроизводимого Markdown подготовь пакет и вызови `node "$SKILL/scripts/gigatool/doc-qa/helpers/readpage.cjs" "$URL" --out "$DIR"` в среде с разрешённым сетевым доступом. Сохрани исходный URL, заголовок и извлечённый текст. Для динамических страниц используй штатный браузер. Доступ к закрытым страницам идёт через штатный handoff.
Для широкого исследования сформулируй вопрос, раздели его на проверяемые части, ищи первичные источники и независимые подтверждения. Читай найденные документы, сверяй даты и сравнимость данных, отмечай противоречия. Для большого корпуса используй существующий поиск и цитаты с привязкой к документам.

Для объёмного исследования раздели независимые вопросы по фактам, региону и периоду. По каждому веди таблицу подтверждений с URL, датой публикации или измерения и тем, что фактически доказано. Статистика, нормативы и цены требуют проверки по первоисточнику. Отмечай цитаты, выводы автора, собственные выводы и пробелы. Противоречия объясняй различиями периода, метода или охвата, если это следует из источников.
