# Доказательная опора медицинского ответа

Медицинское объяснение обязательно опирается на проверенные источники. PubMed
используется явно, совместно с релевантными действующими рекомендациями; техническое
сохранение/экспорт истории не требует поиска. Срочная помощь имеет приоритет.
Уже прочитанную опору можно переиспользовать, проверив актуальность для вопроса
и сохранив дату проверки; не объявляй новый поиск, если использован cache.

## Вопрос и поиск

Выясни только контекст, меняющий применимость: возрастная группа, известное
состояние, беременность/послеродовой период, интересующее действие/обследование
и исход. Для сравнительного вопроса сформулируй population/intervention/comparator/
outcome; для симптома, диагностики или редкого вреда выбери подходящую постановку,
не насильно один шаблон PICO. Публичный запрос обезличен.

1. Проверь подходящую редакцию [КР Минздрава](https://cr.minzdrav.gov.ru/),
   официальный guideline профильного общества/WHO/NICE по задаче. Сохрани
   название, версию/дату, группу, раздел и точную ссылку. JS-рубрикатор при
   необходимости открывай browser-use; ссылка на главную страницу не доказывает
   чтение конкретной рекомендации. Не придумывай endpoint/действующую редакцию.
2. Наш `official_sources.py pubmed search` выполняет реальный E-utilities поиск.
   Используй английские синонимы, title/abstract/MeSH; уточняй дизайн под вопрос.
   Сохрани querytranslation, filters, warnings/errors, дату и охват. Не ограничивай
   весь поиск бесплатным текстом, одним годом или публикациями только с нужным выводом.
3. Обзоры и рекомендации обычно полезны для синтеза; испытания, наблюдательные
   данные, исследования диагностической точности выбирай по вопросу. `systematic[sb]`
   и `Systematic Review[pt]` имеют разный охват. Жёсткие MeSH/возрастные фильтры
   пропускают некоторые свежие записи; проверь также текстовый поиск.
4. Для выбранных PMID сделай batch fetch. DOI/PMID, название, дату, журнал и
   авторов проверь по записи PubMed/Europe PMC/издателя. EFetch helper возвращает
   только часть metadata: отсутствующую дату/автора не восстанавливай из памяти.
5. Проверь publication type, corrections/retraction/erratum/expression of concern.
   Отсутствие отметки в одном endpoint не доказывает отсутствие исправления.
   Препринт, protocol, editorial и результаты исследования различай.

Методика поиска/полей: [PubMed Help](https://pubmed.ncbi.nlm.nih.gov/help/).
Это предметный ограниченный поиск, не автоматически систематический обзор.
NCBI без ключа имеет общий лимит по IP; лимит одного процесса не координирует
всех пользователей. Batch/cache/существующий egress, при отказе Europe PMC/web.
Сторонний MCP ниже >1000 не устанавливается; обычные библиотеки вне этого фильтра.

## Прочитанное и применимость

Читай abstract и необходимые методы/результаты полного текста, если он доступен
законно. Для больших статей используй source-research. Europe PMC fulltext возвращает
OA body sections, это не гарантия полного supplementary/methods coverage или
разрешение коммерческого перепечатывания. Не обходи paywall.

Карточка вывода: тезис; источник/PMID/DOI/дата; покрытие чтения; дизайн;
популяция/условия; сравнение; исход/срок; эффект и доверительный интервал, если
доступны; ограничения; применимость к вопросу пользователя. Нет данных — явно
нет данных. Медицинские рекомендации и результаты отдельных работ не равнозначны.

Не превращай относительный эффект в абсолютный без исходного риска; корреляцию
в причинность; статистическую значимость в клиническую пользу; отсутствие
значимого различия в доказанную эквивалентность; отсутствие зарегистрированного
вреда в безопасность. Несколько обзоров одних испытаний не независимые голоса.
Референс анализа, диагностический порог и индивидуальная лечебная цель различаются.

Если источник даёт GRADE — передай с атрибуцией. Не присваивай формальный GRADE
по abstract и не выдавай процент уверенности модели за качество доказательств.
Опора: [Cochrane Handbook, глава 14](https://www.cochrane.org/authors/handbooks-and-manuals/handbook/current/chapter-14).

## Ответ пользователю

Сначала дай понятный ответ в пределах данных; рядом с существенными медицинскими
тезисами размести ссылки. Объясни релевантность к возрасту/состоянию и важную
неопределённость, затем полезные вопросы/действия для обсуждения с врачом.
Не выдавай список непрочитанных статей за подтверждение ответа. Для объяснения
выписки отдельно цитируй её страницу; фактическое наличие назначения не доказывает
его пользу по литературе. При конфликте источников покажи различия популяции,
исходов, дат и уверенности, не разрешай конфликт сменой лечения от имени агента.

Если PubMed/действующая КР недоступны, обозначь пробел и используй проверенную
доступную опору. При недостатке данных объясни границы, помоги уточнить вопрос
или подготовить приём; не достраивай медицинский вывод без источника.
