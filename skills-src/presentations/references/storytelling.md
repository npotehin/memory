# История, которая ведёт зрителя

Сформулируй одно предложение: «После презентации зритель поймёт/выберет …, потому что …». Затем вопрос, ответ на который нельзя получить уже на первом слайде. Открытие даёт обещание и причину смотреть; финал отвечает на него. Проверяй фактические материалы до драматизации.

## Выбери двигатель

- **Предложение:** текущее положение → цена проблемы → возможное будущее → доказательства → выполнимый следующий шаг. Контраст «сейчас / возможно» по Duarte полезен для убеждения; не растягивай его на каждый слайд.
- **История создания/биография:** цель героя или команды → ограничение → выбор → последствия → следующая трудность → результат. Герой принимает решения, это не обязательно главный персонаж фильма. Не приписывай реальным людям мысли, страхи и мотивы без источника.
- **Объяснение/исследование:** загадка → конкурирующие гипотезы → наблюдение → что оно меняет → границы вывода. Не маскируй отсутствие данных эффектной развязкой.

«Путь героя» — возможная модель, а не обязательные двенадцать этапов. Техническому рассказу часто достаточно цели, препятствия, решения и изменения. Story Spine помогает связать события: соедини сцены словами «но», «потому что», «поэтому». Если везде подходит только «затем», это пока оглавление.

## План до слайдов

Для каждой сцены запиши: **вопрос зрителя → новый вывод → доказательство → визуальное действие → следующий вопрос**. Удаляй сцены, которые не меняют понимание. Подробности идут в заметки/приложение. Обещая показать, как сделан эффект, показывай процесс, а не только готовый кадр.

Пример: «Как продолжить узнаваемый мир?» → «Одного неона недостаточно» → «Нужен физический свет и масштаб» → «Как строятся миниатюры?» → «Что добавляет композитинг?» → «Почему сложный эффект может быть незаметен?» → ответ исходному вопросу. Это схема авторского объяснения, не готовые исторические утверждения.

Кульминация соединяет ранее показанные решения в одном примере. Финал возвращает начальный образ/вопрос с новым пониманием. Награды подтверждают результат, но не заменяют ответ. Избегай сюжетных спойлеров, когда рассказ о производстве обходится без них.

## Проверка плана

Может ли зритель пересказать центральную мысль? Ясно ли, кто действует, чего добивается и что ограничивает выбор? Каждый ли технический факт отвечает на «зачем»? Есть ли причинная связь и оплачено ли обещание открытия? Не придуманы ли эмоции, цитаты или конфликт ради дуги?
