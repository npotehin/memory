# Видео и аудио

Выбери ветку по требуемому результату. Один запрос может пройти несколько веток,
но скачивание или конвертация не требуют storyboard, Node или motion renderer.
Общие среда, проверка и передача —
[references/runtime-and-delivery.md](references/runtime-and-delivery.md).

| Задача | Что прочитать |
|---|---|
| Получить видео, аудио, субтитры или метаданные по URL | [references/acquisition.md](references/acquisition.md), команды — [references/downloads.md](references/downloads.md) |
| Изменить существующий файл: нарезка, склейка, кодеки, размер, звук, HDR, титры | [references/ffmpeg.md](references/ffmpeg.md); закреплённый upstream `008333aaf6722083392eb6bd8bd67b59884a2a26` |
| Создать динамичный ролик из фото/материалов, промо, explainer, motion design | [references/production.md](references/production.md) перед сценарием; затем HyperFrames |
| Творческое видео HyperFrames (по умолчанию) | [references/hyperframes.md](references/hyperframes.md) перед сборкой композиции |

Прочитай ветку перед её выполнением; осмотр файлов может предшествовать чтению.
В составной задаче загружай следующую ветку перед переходом к её этапу.

На «перескажи ролик» сначала получи доступные субтитры и метаданные, затем для большого материала или ответа с цитатами используй
source-research с таймкодами; короткий пересказ выполни по прочитанным субтитрам. Название ролика не доказывает его
содержание. Для HTML/PPTX-презентации используй presentations; здесь результат — видео.

Проверяй идентичность и доступность исходников. Сохраняй оригиналы и происхождение,
используй предоставленную авторизацию, не выводи cookies/ключи. Генерация изображений
не входит в навык. Плейлист не следует автоматически из ссылки на один ролик.

FFmpeg workflow сохраняет точность обрезки, дорожки, цвет/HDR и совместимость
экспорта. Скрипты upstream — проектная зависимость, не содержимое prepared package;
установка и реальные пути описаны в ветке FFmpeg. Внешний MCP для неё не требуется.

Творческая ветка добавляет историю, сценовую карту, разнообразие композиции,
движение и работу со звуком. Перед рендером читай
[references/quality-delivery.md](references/quality-delivery.md): короткий экспорт
проверяет движение, итоговый файл — реальный результат. Сохрани заявленные
пользователем длительность, формат и материалы. Для композиции используй HyperFrames. Не переносить успешную
проверку одного формата/движка на другой.
