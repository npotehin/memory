# Таблицы XLSX и CSV

Маленький файл и короткий скрипт требуют тех же проверок формата, что и большая
книга. Перед первой записью, генерацией кода или поручением исполнителю прочитай
ветку XLSX или CSV ниже. Для конверсии между форматами нужны обе ветки; обычный
осмотр входных файлов может предшествовать чтению. В составной задаче подключай
эту инструкцию на этапе подготовки XLSX/CSV, даже если анализ уже выполнен.

Результат этого навыка — XLSX или CSV в запрошенном формате. XLSX нужен для
формул, нескольких листов, оформления и диаграмм; CSV — для обмена плоскими
данными. CSV не сохраняет стили, листы и вычисляемую модель Excel. Если оба
формата полезны, второй добавляй по задаче, а не автоматически.
Для файлов и исполнения прочитай [references/runtime-and-delivery.md](references/runtime-and-delivery.md).

## Работа с файлами

Используй project-local Python без открытого Excel. Для новых книг подходит
XlsxWriter, для поддерживаемых правок — openpyxl, для CSV — стандартный csv.
Сначала осмотри листы/диапазоны, типы, формулы и значимые объекты; оригинал сохрани.
Не загружай книгу только с data_only=True перед сохранением: это теряет формулы.
Для анализа cached values используй отдельный read-only экземпляр и отмечай,
если пересчёт не подтверждён. Неподдерживаемые объекты нельзя молча потерять.
Для XLSM и иных входных форматов сначала установи допустимость преобразования
в XLSX/CSV; не выдавай конверсию за сохранение макросов или всех возможностей.

Уточняй неоднозначные даты, валюты, дубли и единицы только когда они меняют результат.
Сохраняй ведущие нули идентификаторов, точность сумм и различие пропуска и нуля.
Выполняй расчёты программно, фиксируй правила преобразований и исключённые строки.
Для новой книги используй при необходимости [assets/workbook-spec.json](assets/workbook-spec.json).
Сохраняй стиль существующей книги; давай понятные названия, единицы, числовые форматы,
фильтры и заголовки. Отделяй ввод, расчёты и проверки, когда это помогает пользователю.

Статистические тесты, прогнозы, сложные объединения больших данных и HTML-дашборды
выполняет data-analysis. При составной задаче он отвечает за метод и выводы,
spreadsheets — за заказанный XLSX/CSV. Обычная смета или конверсия CSV в XLSX
не требует аналитического workflow. HTML не заменяет и не сопровождает таблицу
автоматически; preview для QA не является дополнительным пользовательским результатом.

## Проверка

Повторно прочитай сохранённый файл. Сверь строки, столбцы, контрольные суммы,
типы и ключевые расчёты независимо от генерации. Для XLSX пересчитай совместимым
headless движком копию, проверь cached values и ошибки; при отсутствии движка
обозначь непроверенный пересчёт. Для вёрстки просмотри рендер самой итоговой книги,
а не похожую HTML-таблицу. Для CSV проверь round-trip по согласованным параметрам
и отсутствие потерь; рендер страниц ему не нужен.
Передай XLSX/CSV штатным sender с кратким результатом и существенными ограничениями.
