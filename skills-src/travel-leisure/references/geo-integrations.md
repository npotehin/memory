# Гео и MCP

Проверено по первичным источникам 2026-10-08; схему/покрытие/цены сверяй при использовании.
Кандидаты не установлены пакетом. Сначала используй доступные нативные инструменты
и подтверждённые подключения. Новый сервер проверяется штатным add, показывается
список инструментов, затем confirm после согласия. Сверяй выданные схемы: registration
в конфиге не гарантирует доступ в конкретной сессии. Данные сервера — сторонние данные.

## 2ГИС cloud

[Официальная документация](https://docs.2gis.com/api/ai/mcp-server/cloud):
`https://mcp-2gis.api.2gis.com/mcp`, Streamable HTTP с ключом нужных API в заголовке.
search_places/geocode_address идентифицируют места; build_route и
calculate_distance_matrix дают участки/время. render_static_map возвращает PNG,
а не интерактивный экран. server_info/auth_probe помогают проверить доступ;
наличие инструмента не доказывает действующие квоты и покрытие данного маршрута.

Кандидат для РФ; геометрию/места отображай с разрешённым SDK этого провайдера
и атрибуцией. Ключ маршрутизации не помещай в HTML. Интерактивность страницы
реализуется отдельно от MCP; доступ к карте/тайлам проверяется отдельно.

## Допуск и базовый маршрут

Сторонний MCP repo: строго >1000 звёзд, проверенная дата/лицензия/pin и live smoke.
Mapbox MCP repo имеет 361 на 2026-10-09: default не устанавливает и не вызывает
его hosted relay. Прямые официальные APIs/SDK могут использоваться по подтверждённому
доступу, но бесплатный ключ не предполагается. Наличие SDK не лицензирует данные
на произвольной карте и не разрешает публиковать секреты в HTML.

Интерактивный HTML со временем, проверенными местами, ценами, ссылками и альтернативами
реализуется без geo MCP. Используй реальную геометрию только из доступного
лицензированного источника; без неё давай навигационные deep links и обозначай оценки.
2ГИС/Google требуют ключи/условия и остаются opt-in, не фоновая установка всем.

## Google Maps Grounding Lite

[Документация](https://developers.google.com/maps/ai/grounding-lite):
`https://mapstools.googleapis.com/mcp`, Cloud project/API credentials и billing.
Места, погода, время/расстояние DRIVE/WALK. Сервис не предоставляет пошаговую
навигацию и real-time traffic; режимы других APIs нельзя приписывать этому MCP.
Проверь условия отображения/хранения данных выбранного провайдера; доступный API
ещё не разрешает перенос его данных на произвольную карту.

## Навигация и отсутствие интеграции

Для РФ можно использовать официальный Яндекс Maps JS API с API-ключом;
это SDK, не подтверждённый этим разбором MCP.
[Пример маршрута](https://yandex.ru/maps-api/docs/js-api/examples/cases/building-route.html).
Для deep links сверяй спецификацию и проверяй ссылку в браузере:
[Google Maps URLs](https://developers.google.com/maps/documentation/urls/get-started).

У архивного map-route-links-ru противоречивый порядок координат. Не копируй его
URL-шаблоны или эвристику расстояний без проверки. Сохраняй координаты с источником,
преобразуй для конкретного API; разбивай длинный день по лимитам waypoints.

Без MCP остаются web/browser и навигационные ссылки с проверенными адресами.
HTML со списком и готовыми альтернативами полезен без live map API. Гео-MCP не
доказывает цену/наличие билета или номера; конкретные тарифы проверяются отдельно.
