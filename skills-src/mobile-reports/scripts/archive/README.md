# Архив: замена парсеров открытыми библиотеками

Здесь лежит **не рабочая**, а архивная версия. Рабочая — `../site.cjs`
с `require("./vendor/parsers.cjs")`, как было изначально.

## Что это

`parsers-open-source.cjs` — обёртка, которая связывает четыре открытых пакета
вместо закрытого `vendor/parsers.cjs` (640 КБ, не читается, не выгружается).

## Как включить обратно

1. Скопировать `parsers-open-source.cjs` в `scripts/` под именем `parsers.cjs`.
2. В `site.cjs` поменять одну строку:
   `require("./vendor/parsers.cjs")` → `require("./parsers.cjs")`
3. Поставить пакеты — `package.json` рядом, из этой же папки:
   `npm install`
4. Проверить: `node scripts/site.cjs check страница.html`

## Что проверено при разработке

- `check` рабочей карты — ok
- `check` моего отчёта — ok
- плохая страница — 5 ошибок найдено
- `bundle` — внешние ссылки убраны
- `archive` — ZIP создаётся
- тесты скилла — 3 passed

## Ограничения

- селекторы: только `tag`, `tag[attr]`, перечисление через запятую
- `valueParser` упрощён до регулярных выражений
- полного движка селекторов нет
